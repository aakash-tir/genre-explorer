Pipeline — built (v1 complete)

Runtime — shipped

  • • Zod re-validates on load — a bad refresh fails loudly
  • • Canvas map is live: gradients, LOD, wheel/drag camera, URL zoom
  • • Personal lens: PKCE (≤5 users) → top artists → weighted highlights + branch-out suggestions · localStorage, no accounts
