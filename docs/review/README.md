# Review queue

Things found but **not acted on**, parked here for a single review session rather than
fixed piecemeal. Each file is a dated snapshot: what was found, the evidence that found
it, why it matters, and the proposed fix — enough that the reviewer can decide without
re-investigating.

This is a staging area, not a second backlog. `docs/future.md` remains the backlog of
record; anything here also has a one-line bullet there pointing back at the write-up, so
the two cannot drift apart.

**When an item is settled:** do the work (or decide against it), delete it from the
review file, and remove its bullet from `docs/future.md`. When a file is empty, delete
it. `logs/` and the PR history are the record of what was finished — nothing here should
survive as a "done" list.
